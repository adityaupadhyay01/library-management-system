📚 Library Management System (C)

A console-based Library Management System built using C that allows users to manage book records efficiently through file handling.

This project demonstrates core concepts of structured programming, file management, and data handling in C.

🚀 Features
📖 Add new books to the library
📤 Issue books to users
📥 Return issued books
📋 View all available books
💾 Persistent storage using file handling
🛠️ Tech Stack
Language: C
Concepts Used:
File Handling (fopen, fwrite, fread, etc.)
Structures
Conditional Statements
Loops
📂 Project Structure
├── 01.c          # Main source code
├── library       # Compiled executable (after build)
├── data files    # Stored book records (generated at runtime)
⚙️ How to Run
1. Compile the program
gcc 01.c -o library
2. Run the executable
./library
🧠 What You’ll Learn
How real-world systems like libraries manage records
Basics of file-based data persistence
Structuring a complete CLI-based application
Writing modular and maintainable C code
